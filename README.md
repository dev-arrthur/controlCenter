# Control Center — novo site institucional

Front-end estático em **HTML5 + CSS3 + JavaScript + Bootstrap 5**, separado em páginas para facilitar manutenção, SEO e evolução do projeto.

## Estrutura atual

- `index.html` — Home, hero, comparativo de planos, soluções, FAQ e CTAs
- `empresa.html` — página institucional
- `solucoes.html` — página com todas as soluções atuais
- `equipe.html` — página da equipe
- `contato.html` — contato e formulário integrado ao WhatsApp
- `assets/css/style.css` — identidade visual e responsividade compartilhadas
- `assets/js/main.js` — WhatsApp, área do cliente, formulário e animações
- `robots.txt` — regras de rastreamento
- `sitemap.xml` — sitemap inicial

## Configuração pendente

No arquivo `assets/js/main.js`, atualizar `clientAreaUrl` assim que o domínio definitivo da área do cliente for informado.

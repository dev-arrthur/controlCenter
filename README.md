# Control Center

Novo site institucional da Control Center, desenvolvido em HTML5, CSS3, JavaScript e Bootstrap 5.

A estrutura foi separada em páginas para facilitar manutenção, SEO e futuras evoluções.

## Estrutura inicial

- `index.html` — Home e comparativo de planos
- `empresa.html` — Empresa
- `solucoes.html` — Soluções
- `equipe.html` — Equipe
- `contato.html` — Contato
- `solucoes/` — páginas individuais de serviços
- `assets/css/style.css` — estilos compartilhados
- `assets/js/main.js` — scripts compartilhados

> Projeto em desenvolvimento. As copies, imagens definitivas e URL da área do cliente serão refinadas nas próximas etapas.
